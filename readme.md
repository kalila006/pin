## Nama
Veifikasi PIN

## deskripsi
Program Verifikasi PIN merupakan program sederhana yang dibuat menggunakan bahasa pemrograman Go. Program ini berfungsi untuk memeriksa PIN yang dimasukkan oleh pengguna. Pengguna diberikan maksimal tiga kali kesempatan untuk memasukkan PIN yang benar.

## fitur-fitur program
1. verifikasi PIN
2. Meminta pengguna memasukan PIN melalui terminal
3. Memberikan maksimal tiga kali kesempatan untuk memasukan pin
4. Menampilkan pesan jika PIN yang dimasukan benar
5. Menampilkan pesan jika PIN yang dimasukan salah
6. Menampilkan pemberitahuan akses gagal

## Teknologi yang digunakan 
* Bahasa pemrograman Go (Golang).
* Visual Studio Code sebagai editor kode.
* Git untuk mengelola versi program.
* GitHub sebagai tempat penyimpanan repository.

## Cara menjalankan Program
1. Pastikan bahasa pemrograman Go sudah terinstal.
2. Buka folder project melalui Visual Studio Code.
3. Buka terminal pada folder project.
4. Jalankan perintah berikut:
go run pin.go
5. Masukkan PIN ketika program meminta input.
6. Program akan menampilkan hasil verifikasi PIN.
